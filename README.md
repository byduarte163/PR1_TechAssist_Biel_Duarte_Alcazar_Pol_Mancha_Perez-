# PR1_TechAssist_Biel_Duarte_Alcazar_Pol_Mancha_Perez-

Integrantes: Biel Duarte Alcazar i Pol Mancha Perez

El objetivo del diseño es crear un modelo de base de datos que permita organizar y relacionar de forma eficiente la información de clientes, técnicos, departamentos, incidencias y servicios. Se busca evitar la duplicidad de datos, mantener la información actualizada, garantizar su integridad y facilitar su consulta y gestión. 

El modelo Entidad-Relación diseñado para TechAssist representa la información de clientes, técnicos, departamentos, incidencias y servicios, así como las relaciones entre ellos. Incluye atributos específicos, claves identificadoras, cardinalidades y restricciones. También contempla los teléfonos multivaluados de los clientes, la edad derivada y la dirección compuesta de los técnicos, las intervenciones entre técnicos e incidencias y la especialización de los servicios en presenciales y online.
